# AI Image Social

## Project Overview

AI Image Social is a web-based platform that allows users to create and post AI-generated images using the DALL-E Chat GPT engine. The platform provides a social timeline for users to view and collaborate on artwork.

![enter image description here](https://akin-gungor.vercel.app/assets/dalle-21f48b07.png)

## Features

-   **User Authentication:** Secure user sign-up and login.
-   **AI Image Generation:** Create images using the DALL-E 2.0 engine.
-   **Social Interaction:** Like, comment, and collaborate on posts.
-   **Responsive Design:** Accessible on various devices.

## Installation

1.  Clone the repository:
    
    bash

    ```
    git clone https://github.com/akngngr/ai-image-social.git
    cd ai-image-social    
3.  Install dependencies:
    
    bash
    
    ```
    cd client
    npm install
    cd ../server
    npm install    
4.  Start the development server:
    
    bash

    ```   
    cd client
    npm start
    cd ../server
    npm start
## Usage

1.  Register and log in to the platform.
2.  Generate or upload an AI-generated image.
3.  Share your image with the community.
4.  Interact with posts by liking, commenting, and collaborating.
